## Nouveautés

### Importer ses données sur le site : plus facile à trouver
- Sur le site, nouvelle section **Paramètres → « Importer depuis l'application desktop »**. Elle explique les étapes et propose le bouton **« Choisir le fichier exporté… »**.
- Une fois le fichier importé, **« Ouvrir ce profil maintenant »** mène directement au mot de passe du profil ajouté. Votre profil web actuel n'est pas touché.
- Sur l'écran d'accueil du site, le bouton **« Importer une sauvegarde (desktop ou site)… »** est désormais visible directement : plus besoin de passer par « Ajouter un utilisateur ».
- Dans l'application, la fenêtre **« Exporter pour la version web… »** indique ces nouveaux emplacements.

Rappel : dans l'application, *Paramètres → Sauvegardes → « Exporter pour la version web… »* crée un fichier chiffré. Sur le site, vos comptes, opérations, récurrences, catégories et étiquettes s'y retrouvent, avec des soldes identiques au centime.

## Installation
- Téléchargez **FinanceApp-0.3.2.msi** ci-dessous et lancez-le. Installé par-dessus une version précédente, il la remplace et **conserve vos profils et vos données**.
- L'installateur n'est pas signé : si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
