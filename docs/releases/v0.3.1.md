## Nouveautés

### FinanceApp existe aussi en version web
- Une **version navigateur** de FinanceApp fait son apparition : tableau de bord, comptes, transactions, à venir, récurrences, **disponible réel**, prévisions, catégories. Ce sont les mêmes calculs que l'application.
- **Vos données restent dans votre navigateur**, chiffrées avec votre mot de passe maître : le site n'envoie rien sur Internet et celui qui l'héberge ne voit aucune donnée.
- Le site est utilisable sur téléphone, avec plusieurs profils, une clé de récupération, un verrouillage automatique et une sauvegarde chiffrée.
- Le site se trouve dans le dossier `web/` du dépôt, avec son guide d'hébergement (`web/README-WEB.md`).

### Reprendre ses données de l'application sur le site
- Nouveau : **Paramètres → Sauvegardes → « Exporter pour la version web… »**. Choisissez un mot de passe : l'application crée un **fichier chiffré**, et une clé de récupération s'affiche.
- Sur le site : **« Restaurer une sauvegarde »** puis ce mot de passe. Vos comptes, opérations, récurrences, catégories et étiquettes y sont, **avec des soldes identiques au centime**.
- Ne sont pas repris, car ils n'existent pas encore sur le site : budgets, objectifs, crédits (leurs échéances restent des récurrences), simulations, justificatifs. Le disponible réel du site ne déduit donc pas les budgets ni les objectifs.
- C'est une copie à un instant donné : l'application et le site ne se synchronisent pas.

## Installation
- Téléchargez **FinanceApp-0.3.1.msi** ci-dessous et lancez-le. Installé par-dessus une version précédente, il la remplace et **conserve vos profils et vos données**.
- L'installateur n'est pas signé : si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
