## Nouveautés

### Budgets et objectifs d'épargne sur le site
- Deux nouveaux écrans sur le site : **Budgets** et **Objectifs d'épargne**. Le tableau de bord affiche aussi un aperçu des budgets du mois.
- **Budgets** : un plafond mensuel par catégorie, sous-catégories comprises. Choisissez le mois et suivez la part consommée : une barre, le pourcentage écrit et un état (✓ dans le budget, ! proche de la limite, ■ atteint, ✕ dépassé).
- **Objectifs** : un montant visé et une échéance facultative. L'épargne mensuelle nécessaire est calculée. Le montant peut être suivi à la main (« Verser / retirer… ») ou par le solde d'un compte, par exemple un livret dédié.
- Les budgets et objectifs marqués « à réserver » sont déduits du **disponible réel**, avec les mêmes calculs que l'application, au centime près.
- « Exporter pour la version web… » reprend désormais vos budgets et objectifs : **le disponible réel du site est le même que celui de l'application**.

### Ramener dans l'application ce que vous avez saisi sur le site
- Nouveau : **Paramètres → Sauvegardes → « Importer depuis la version web… »**. Choisissez la sauvegarde téléchargée depuis le site (*Paramètres → Télécharger une sauvegarde chiffrée*), puis le mot de passe du profil du site.
- Chaque compte du site est associé au compte de même nom. Vous pouvez aussi le **créer** ou **ne pas l'importer**.
- Un aperçu classe chaque opération :
  - **nouvelle** : cochée ;
  - **prévue ici et effectuée sur le site** : elle passe à « effectuée » ;
  - **doublon possible** et **modifiée sur le site** : signalée et décochée ;
  - **déjà présente** : ignorée.
- **Rien d'ambigu n'est importé sans votre accord.** Réimporter le même fichier n'ajoute rien.
- Une échéance récurrente validée ou ignorée sur le site l'est aussi dans l'application : elle n'est pas comptée deux fois.
- L'import se défait depuis l'écran **Imports** (« Défaire cet import »).
- Les deux versions ne se synchronisent pas toutes seules : vous les rapprochez par fichier, quand vous le souhaitez, sans passer par Internet.

## Installation
- Téléchargez **FinanceApp-0.4.0.msi** ci-dessous et lancez-le. Installé par-dessus une version précédente, il la remplace et **conserve vos profils et vos données**.
- L'installateur n'est pas signé : si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
- Pour le site, mettez à jour les fichiers hébergés avec ceux de cette version (dossier `web/`, voir `web/README-WEB.md`). Les données des utilisateurs, stockées dans leur navigateur, ne sont pas touchées.
