## Correctif

### Recherche de nouvelles versions plus fiable
- *Paramètres → Mises à jour → « Vérifier maintenant »* pouvait échouer avec « request timed out » sur certains ordinateurs (antivirus qui inspecte les connexions HTTPS, proxy configuré dans Windows).
- L'application passe désormais par le **proxy de Windows** s'il y en a un, utilise un protocole accepté par ces antivirus et attend jusqu'à 20 secondes.
- Si GitHub ne répond pas par la première voie, un **second essai** passe par la page publique des versions.
- En cas d'échec, le message est clair et en français (par exemple « GitHub n'a pas répondu à temps »).

Rien ne change pour vos données : la vérification reste désactivée par défaut, n'envoie aucune donnée financière et ne télécharge rien automatiquement.

## Installation
- Téléchargez **FinanceApp-0.3.3.msi** ci-dessous et lancez-le. Installé par-dessus une version précédente, il la remplace et **conserve vos profils et vos données**.
- L'installateur n'est pas signé : si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
